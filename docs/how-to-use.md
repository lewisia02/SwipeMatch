# 使い方ガイド（参加者向け）

このドキュメントは、SwipeMatch（社内AIイベント ロゴ投票アプリ）に**参加者として参加する方**向けの使い方ガイドです。管理者・運営向けの操作（コンペの開催やフェーズ切り替えなど）はこのドキュメントの対象外です。

同じ内容は、アプリ内の使い方ガイド画面（`/how-to-use`。トップページ「使い方はこちら」リンクから遷移）でも閲覧できます。実際の画面写真つきで確認したい場合はそちらをご覧ください。

## 参加の流れ（全体像）

1. QRコードを読み取る、またはURLにアクセスする
2. 名前を入力する（本名でなくてOK）
3. **投稿受付中**であればロゴ画像を投稿する
4. **投票受付中**になったら、スワイプで1次選考する
5. キープした作品から決選投票する
6. （同着が発生した場合のみ）ランオフ投票する
7. 結果発表を待つ（会場のスクリーンで発表されます）

コンペは「投稿受付中 → 投票受付中 → 結果発表」の順にフェーズが進みます。フェーズの切り替えは運営が行うため、今どのフェーズかによって、あなたができる操作（投稿・投票）が変わります。

## 1. 参加方法

会場で案内されるQRコードを読み取るか、共有されたURL（`/c/〇〇〇〇〇〇`のような専用URL）にアクセスしてください。ログインやアカウント登録は不要です。

## 2. 名前を入力する

初めてアクセスすると、「お名前を入力してください」という画面が表示されます。

- 入力した名前は、ロゴを投稿したときに投稿者名として使われます
- 本名である必要はありません（何でも構いません）
- 一度入力すれば、同じスマートフォン・同じブラウザで使い続ける限り再入力は不要です

「はじめる」を押すと、コンペのトップ画面に進みます。

## 3. ロゴ画像を投稿する（投稿受付中のみ）

トップ画面で「📤 画像を投稿する」を押すと投稿画面に進みます。

- ロゴ画像を選択します（jpg / png / heic / webp、10MB以下）
- 「一口メモ」に作品への思いなどを入力します（1〜200文字、必須）
- 投稿者名は2.で入力した名前がそのまま使われるため、この画面で入力する欄はありません
- 「投稿する」を押すと完了です。1人で複数件投稿しても構いません

投稿受付中でない場合、このボタンは非活性（「準備中」または「受付終了」）になります。

## 4. スワイプで1次選考する（投票受付中のみ）

トップ画面で「🗳 投票へ進む」を押すと、投稿されたロゴが1枚ずつランダムな順番で表示されます。

- 気に入ったら **右スワイプ、または「♥ キープ」ボタン**
- 見送るなら **左スワイプ、または「✕ 次へ」ボタン**
- スワイプ操作が苦手な場合は、必ずボタンでも同じ操作ができます
- 「次へ」を選んでも、その作品が減点されるような仕組みではありません。単に決選投票の候補から外れるだけです

すべての作品を仕分けると、決選投票へ進むボタンが表示されます。**1枚もキープしていない場合は先に進めません**。1枚以上キープしてから次に進んでください。

## 5. 決選投票する

キープした作品がグリッド表示されます。

- 気に入った作品を**最大3つまで**タップして選択します（すでに3つ選んだ状態で4つ目をタップすると選択できません）
- 「投票する」を押すと投票完了です
- **一度投票すると、同じブラウザからは再投票できません**（取り消し・変更もできません）ので、選び終わってから投票してください

投票が完了すると自動的にトップ画面に戻り、「投票ありがとうございました。結果発表をお楽しみに🎉」のメッセージが表示されます。

## 6. ランオフ投票する（同着が発生した場合のみ）

決選投票の結果、1位が同数得票になった場合のみ、運営が「ランオフ」という再投票を行うことがあります。ランオフが開始されると、トップ画面に「⚖️ ランオフ投票へ進む」ボタンが表示されます。

- 同着になった作品の中から**1つだけ**選んで投票します
- **通常の決選投票（5.）に投票していない場合は、ランオフには参加できません**。「通常の決選投票をしていないため、ランオフには参加できません」と表示されます
- ランオフ後もまだ同着が続く場合、運営の判断で再度ランオフが行われることがあります（その場合も同じ手順です）

ランオフが発生しなかった場合、この手順はありません。そのまま結果発表をお待ちください。

## 7. 結果発表を待つ

決選投票（・ランオフ投票）が終わったら、あとは会場のスクリーンでの結果発表をお楽しみください。アプリ上での操作はここまでです。

## よくある質問（FAQ）

**Q. 名前は本名を入れないといけませんか？**
A. いいえ、何でも構いません。ニックネームでも問題ありません。

**Q. ロゴは何件でも投稿できますか？**
A. はい、投稿受付中であれば同じ人が複数件投稿しても構いません。

**Q. 投稿や投票をやり直したいです。**
A. 投稿は複数件行えますが、決選投票・ランオフ投票は一度送信すると同じブラウザからは変更・取り消しができません。選び終わってから投票してください。

**Q. スマートフォン以外（PC・タブレット）でも参加できますか？**
A. 参加者向けの画面はスマートフォンでの利用を想定して作られていますが、PC・タブレットのブラウザからでも同じ手順で参加できます。

**Q. 自分が投稿した作品に自分で投票してもいいですか？**
A. 問題ありません。

**Q. 別のスマートフォンで開き直すとどうなりますか？**
A. 投票済みかどうかはブラウザ単位で判定されるため、別の端末・別のブラウザで開き直すと、そちらでも決選投票ができてしまいます。これは個人の識別・認証を目的としたシステムではないためです。参加者どうしの信頼にもとづく運用ですので、1人1回の参加にご協力ください。

**Q. 画面に「準備中」「受付終了」と表示されて操作できません。**
A. 現在のフェーズ（投稿受付中・投票受付中など）に応じて操作できる内容が変わります。運営がフェーズを切り替えるまでお待ちください。
