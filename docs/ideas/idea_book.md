# 社内AIイベント ロゴ投票アプリ アイデア帳 兼 要件定義書

## 1. プロジェクト概要
社内AIイベントのアイスブレイクとして開催される「ロゴ作成大会」のための、Webベースの画像アップロード・投票アプリです。参加者が手軽に楽しみつつ、大人数でもスムーズに公平な投票が行える仕組みを提供します。

## 2. ターゲットと利用環境
- **ユーザー（参加者）**: 社内メンバー（最大200名程度）
- **利用デバイス**: 社員用スマートフォン（ブラウザからアクセス）
- **アクセス制限**: 認証の手間を省くため、URLを知っていれば誰でも入れる仕様（機密情報は扱わないワンショットなシステム）

## 3. アプリの基本フロー ＆ ユーザー体験 (UX)
1. **トップ画面**
   - イベントの概要説明と、「画像を投稿する」「投票へ進む」の2つの導線を提供。
2. **画像アップロード機能**
   - 入力項目: ロゴ画像（必須）、投稿者名（必須）、一口メモ（必須・作品への思い）
   - **プライバシー配慮**: 投稿者名は運営側（管理者画面）のみ確認可能とし、投票画面では完全匿名とします。
3. **スワイプ式（Tinder風）UIによる1次選考**
   - 投稿された画像と一口メモが、ランダムな順番で1枚ずつ画面に表示されます。
   - ユーザーは直感的に「キープ（右スワイプ）」か「次へ（左スワイプ）」に仕分けを行います。
   - **メリット**: 画像が100〜200枚と多くても迷わずサクサク選べ、表示順による有利不利がなくなります。また、同僚の作品を「Dislike」する心理的罪悪感を「キープして温存する」という前向きな表現で解消します。
4. **最終投票（決選投票）**
   - 1次選考で自分が「キープ（右スワイプ）」した画像だけがグリッド形式で一覧表示されます。
   - ユーザーはその中から、本当に優勝にふさわしいと思う作品を厳選して最終投票を行います。
5. **結果発表（管理者画面）**
   - URL直叩きなどでアクセスする専用画面。
   - 最終得票数（Like数）の多い順にランキング形式で画像、一口メモ、そして**投稿者名（本名）**を表示します。イベント本番でこの画面をスクリーンに映して優勝者を発表します。

## 4. 開発方針 ＆ 技術スタック
個人開発に近い形でラフに、かつ爆速で開発を進めるためのモダンな構成です。
- **開発ツール**: Claude Code
- **フロントエンド**: Next.js (App Router), Tailwind CSS
- **バックエンド/ストレージ**: Supabase (Database & Storage) ※無料枠の範囲内で十分に運用可能
- **スワイプUIの実装**: `react-tinder-card` または `framer-motion`

## 5. データベース設計イメージ (Supabase)
### `logos` テーブル (投稿されたロゴデータ)
- `id` (uuid, primary key)
- `image_url` (text) - Supabase Storage内の画像URL
- `uploader_name` (text) - 投稿者の氏名（運営画面でのみ使用）
- `memo` (text) - 一口メモ（投票画面に表示）
- `created_at` (timestamp)

### `votes` テーブル (最終投票データ)
- `id` (uuid, primary key)
- `logo_id` (foreign key -> logos.id)
- `created_at` (timestamp)
