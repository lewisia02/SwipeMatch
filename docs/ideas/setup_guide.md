# Supabase 事前準備＆初期セットアップ手順書

本手順書は、ロゴ投票アプリのバックエンドとして「Supabase」を利用するための事前準備をまとめたものです。
所要時間は5〜10分程度です。すべて無料枠（Freeプラン）の範囲内で完了します。

## 1. アカウントの作成
1. [Supabase公式サイト](https://supabase.com/) にアクセスします。
2. 画面右上の **「Start your project」** または **「Sign In」** をクリックします。
3. **「Continue with GitHub」** を選択し、お持ちのGitHubアカウントでログイン（連携）するのが最もスムーズです。
   （※メールアドレスでの登録も可能です）

## 2. 新規プロジェクトの作成
1. ログイン後のダッシュボード画面で、**「New project」** をクリックします。
2. 所属するOrganization（通常はご自身のアカウント名が表示されます）を選択します。
3. プロジェクトの作成画面で以下の項目を入力します：
   - **Name**: 任意のプロジェクト名（例: `ai-event-logo-app`）
   - **Database Password**: 強固なパスワードを入力します。
     ⚠️ **重要:** このパスワードは後でデータベースを直接操作する際などに使用する可能性があるため、必ずメモしておいてください。
   - **Region**: アクセス速度を上げるため、日本からの利用であれば **`Tokyo (ap-northeast-1)`** を選択します。
   - **Pricing Plan**: **`Free`** を選択します。
4. **「Create new project」** をクリックします。
   ※データベースの構築に数分（1〜2分）かかりますので、画面が変わるまでそのままお待ちください。

## 3. 環境変数（APIキーとURL）の取得
プロジェクトの構築が完了したら、アプリ（Next.js等）とSupabaseを連携するための接続情報を取得します。

1. プロジェクトのダッシュボード（Home）を下の方へスクロールするか、左側メニューの一番下にある歯車アイコン（Project Settings） > **「API」** を開きます。
2. 以下の2つの情報をコピーし、手元のメモ帳などに控えておきます。
   - **Project URL**: `https://xxxxxxxxxxxxxx.supabase.co` という形式のURLです。
   - **Project API keys (anon / public)**: `eyJhbGciOi...` から始まる長い文字列です。
