# 画面設計スキル

このスキルは、高品質な画面(UI)設計書を作成するための詳細ガイドです。
Web/GUI アプリケーションの画面構成・画面遷移・状態設計・デザインシステムを定義し、
機能設計書で定義された「何ができるか」を「どう見せ・操作するか」に落とし込みます。

## 前提条件

画面設計を開始する前に、以下を確認してください:

### 必須ドキュメント

1. `docs/product-requirements.md` (PRD)
2. `docs/functional-design.md` (機能設計書)

画面設計書は、PRD のユーザーストーリーと機能設計書の機能を、具体的な画面・
コンポーネント・状態として設計します。

## 既存ドキュメントの優先順位

**重要**: `docs/ui-design.md` に既存の画面設計書がある場合、
以下の優先順位に従ってください:

1. **既存の画面設計書 (`docs/ui-design.md`)** - 最優先
   - プロジェクト固有の画面設計とデザインシステムが記載されている
   - このスキルのガイドより優先する

2. **このスキルのガイド** - 参考資料
   - 汎用的なテンプレートと例
   - 既存設計書がない場合、または補足として使用

**新規作成時**: このスキルのテンプレートとガイドを参照
**更新時**: 既存設計書の構造と内容を維持しながら更新

## 出力先

作成した画面設計書は以下に保存してください:

```
docs/ui-design.md
```
